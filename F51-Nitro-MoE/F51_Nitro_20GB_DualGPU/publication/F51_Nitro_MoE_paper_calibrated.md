# Abstract

This note reports a local measurement study of GPT-OSS 120B MXFP4 inference on a consumer
RTX 5060 Ti 16 GB system using a patched llama.cpp/F51 runtime. The archived run identifies
the model geometry, expert tensor size, GPU memory buffers, token throughput, F51 cache
hit-rate checkpoints, and a prompt-cache/SWA checkpoint correction. The current evidence
supports a narrow claim: GPT-OSS 120B MXFP4 can be loaded and served locally with partial
MoE CPU/GPU placement, but the measured archived generation speed is 3.22 tok/s over 33
generated tokens. Larger Qwen throughput claims from earlier notes require fresh raw logs
before journal submission.

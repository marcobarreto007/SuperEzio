RECOMENDACAO FINAL
================================================================================

  Melhor provider: yFinance

  BUG ENCONTRADO:
  AKShareProvider._parse_intraday_timeframe(): timeframe '1M', '3M', '6M'
  sao interpretados como intraday (1 minuto) porque o metodo verifica
  se o nome termina com 'm' (case-insensitive). '1M' vira '1m' e cai
  no ramo intraday, ignorando o mapeamento _PERIOD_MAP que mapeia
  corretamente '1M' -> 'monthly'.

  Cadeia recomendada (prioridade):
    1. Finnhub (se FINNHUB_API_KEY setada — melhor latencia)
    2. TwelveData (se TWELVE_DATA_API_KEY setada — intraday suportado)
    3. yfinance (sempre disponivel, OHLCV completo, sem key)
    4. AKShare (gratis, daily funciona, intraday via China)

  NOTA: Este ambiente nao tem FINNHUB_API_KEY, TWELVE_DATA_API_KEY,
  nem ALPHA_VANTAGE_API_KEY. Apenas yfinance esta operacional,
  e AKShare com conectividade intermitente a servidores chineses.

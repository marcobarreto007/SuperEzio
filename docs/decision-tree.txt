Resumo do fluxo decisional
===========================
| Etapa       | Quem decide              | Input              | Output              | Fallback                        |
|-------------|--------------------------|--------------------|---------------------|---------------------------------|
| Roteamento  | HybridIntentClassifier   | Mensagem usuario   | Rota + intent+ticker| Deterministico → Golden → LLM   |
| Coleta      | SubprocessDataCollector  | Ticker/filtros     | Trace multi-fonte   | Timeout 60s → erro parcial      |
| Veredito    | F51HubAdapter→F51Engine  | Trace + features   | Score 0-1 + fatores | Grafo roda com dados parciais   |
| PennyLab    | 4 experts especializados | Ticker             | Decisao + scores    | ImportError → WATCH_ONLY        |
| Experts     | AgentSelector+12 agentes | AssetProfile       | N resultados paral. | Provider offline → skip         |
| CEO         | CEO Nemotron-Nano-12B merged | Prompt completo    | Texto final         | CEO offline → MODEL_ERROR       |
| Explicacao  | ExplainEngine            | Veredito+texto CEO | Stream de chunks    | Skip se sem veredito            |


Frontend (ChatGPT-style — frontend/index.html)
================================================
Arquivo unico, self-contained (CSS + JS inline).
Dependencia externa: apenas Lucide Icons (CDN).

Layout 3 zonas:
  TOP BAR:    logo + status dot (GET /health) + ticker input (GET /api/chart-data/{ticker})
              + timeframe selector + chart toggle
  CHAT AREA:  user bubbles (dark) + CEO bubbles (light) com streaming NDJSON
              + cards expansivos inline (F51, PennyLab, Crisis, Data, Experts)
  BOTTOM BAR: textarea + Send button (POST /task/submit) + portfolio drawer (localStorage)

Cada evento NDJSON → componente UI:
  STREAM_START → "thinking..." dots animados
  CHUNK → texto streaming no bubble (strip <think> blocks)
  F51_VERDICT → card com anel SVG de confianca + 6 fatores + hub risk bar
  PENNYLAB_ANALYSIS → card com 5 scores + barras coloridas
  CRISIS_MATH → card com regime badge + alertas + 12 model tiles
  DATA_COLLECTED → card com grid 5x2 de fontes (ok/partial/error)
  PIPELINE_STEP → breadcrumb de 7 dots atualizado em tempo real
  EXPERT_STARTED/DONE/SKIPPED → grid 4x3 de expert tiles
  INTENT_CLASSIFIED → chip minúsculo (quase invisível)
  ERROR → banner vermelho no chat
  STREAM_END → finaliza mensagem, salva no journal (localStorage)

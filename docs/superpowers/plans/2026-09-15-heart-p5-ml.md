# Heart P5 ML Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** First-class path curator and weighter — not an add-on. Decide what to keep from the event/price firehose, assign weight to surviving paths (event type × window × ranking axis), and output P(triple-barrier success | side, features) with calibrated probabilities, purged CV, and a complete attempt log for Deflated Sharpe. `river.expert` updates ranking weights when the barrier closes.

**Architecture:** Labels from existing `evaluate_triple_barrier` with session-aligned vertical barrier and GARCH-scaled widths. LightGBM primary, CatBoost independent second model. Venn-Abers for probabilities; MAPIE ACI for interval adaptation when the barrier resolves. `skfolio.model_selection.CombinatorialPurgedCV` only — never mlfinpy. tsfresh selection **inside** each fold. MLflow + Optuna are the DSR denominator. `river.drift` decides retrain; `river.expert` updates ranking weights when the barrier closes.

**Tech Stack:** Python 3.12 CPU: lightgbm, catboost, skfolio, mapie, venn-abers, mlflow, optuna, river, tsfresh, stumpy, shap, statsmodels/arch (from P1).

**Spec:** `docs/superpowers/specs/2026-09-15-modulo-coracao-roadmap.md` §3, §5, §6 Peça 5, §7–8.
